## URL 结构
```
https://api.example.com:8080/users/1?name=张三&age=25#section
└─┬─┘ └──────┬──────┘└─┬┘ └────┬────┘ └──────┬──────┘ └──┬──┘
 协议      主机       端口  路径          查询参数       锚点
(scheme)  (host)    (port) (path)      (query)       (fragment)
```

## 传参方式速查表（gin 为例）

|传参方式|URL / 位置示例|gin 取值|备注|
|---|---|---|---|
|**路径参数**|`/users/:id`|`c.Param("id")`|用 `:` 定义|
|**通配**|`/files/*path`|`c.Param("path")`|用 `*` 定义|
|**查询参数**|`/search?k=v`|`c.Query("k")` / `c.DefaultQuery` / `c.QueryArray`||
|**表单**|POST body|`c.PostForm("k")` / `c.DefaultPostForm` / `c.PostFormArray`|urlencoded / multipart|
|**文件**|multipart|`c.FormFile("f")` / `c.MultipartForm()`||
|**JSON Body**|body|`c.ShouldBindJSON(&obj)`||
|**自动绑定**|body|`c.ShouldBind(&obj)`|按 Content-Type|
|**路径→struct**|`/users/:id`|`c.ShouldBindUri(&obj)`|tag `uri:"id"`|
|**Header**|请求头|`c.GetHeader("k")`||
|**Cookie**|Cookie|`c.Cookie("k")`||

## 几个关键区别

|点|gin|echo|chi|标准库 1.22+|
|---|---|---|---|---|
|路径参数语法|`:id`|`:id`|`{id}`|`{id}`|
|通配语法|`*path`|`*` / `:path`|`*`|`{path...}`|
|取路径参数|`c.Param`|`c.Param`|`chi.URLParam`|`r.PathValue`|
|取查询参数|`c.Query`|`c.QueryParam`|`r.URL.Query()`|`r.URL.Query()`|
|取表单|`c.PostForm`|`c.FormValue`|`r.FormValue`|`r.FormValue`|
|绑定 JSON|`c.ShouldBindJSON`|`c.Bind`|手动 decode|手动 decode|
|分组|`r.Group`|`e.Group`|`r.Route`|手动|
|方法匹配|自动|自动|自动|`"GET /x"`|
