我主要用 Claude Code + Opus，Codex 试得少，但 AI 做设计个痛点应该差唔多——提示词再靓，都抵不过前期设计系统定义唔清。

我个经验系分三层喂：

第一层：设计系统（最紧要）
颜色 token、字体阶梯、间距 scale、圆角规则、阴影层级——呢啲写死，唔好畀 AI 自由发挥。我会直接贴一段 JSON 或者 Tailwind config 嘅 snippet，确保每次生成个基础一致。

第二层：场景同情绪
唔好只讲「做个登录页」，要讲「用户第一次打开，未信任我哋，要降低戒心」。情绪、场景、用户状态写清楚，AI 先至识得点排信息层级。

第三层：参考锚点
畀具体例子——「按钮 hover 效果参考 Linear 个 subtle lift，唔要 Material Design 个水波纹」。有锚点 AI 先至唔会乱飞。
