## 中间件执行时机
- 中间件运行在「路由匹配之后、Handler 执行之前」。它对每个匹配到的请求都执行一遍，包裹住 Handler。
```
请求进来
  │
  ├─ 框架层：路由匹配 /register → 找到 handler
  │
  ├─ 中间件链开始 ──────────────────┐
  │    Logger前（记录开始时间）      │
  │    Auth前（校验 token）          │  ← 中间件层
  │    CORS前（设置跨域头）          │
  │                                  │
  │    ┌─── Handler 函数 ───┐        │
  │    │  ShouldBindJSON    │        │  ← Handler 层（接入层）
  │    │  validator 校验    │        │
  │    │  调 Service         │        │
  │    └────────────────────┘        │
  │                                  │
  │    CORS后                        │
  │    Auth后                        │
  │    Logger后（记录耗时）          │
  └──────────────────────────────────┘
  │
响应返回
```

## 中间件设计
```
func Logger() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()          // ← Logger 前

        c.Next()                     // ← 执行下一个中间件 / Handler

        latency := time.Since(start) // ← Logger 后
        log.Printf("耗时: %v", latency)
    }
}
```
