请为【产品名称】设计一个具有“工程仪器面板 + 技术文档 + 克制复古未来感”的响应式网页。

产品信息：
- 产品类型：【填写，例如 AI 开发工具 / 个人技术博客 / SaaS 平台】
- 目标用户：【填写】
- 页面目标：【填写，例如引导用户了解产品并注册】
- 核心功能：【填写 3～6 个】
- 主要 CTA：【填写】
- 页面语言：简体中文
- 技术实现：【React/Vue/HTML + CSS 等】

一、设计目标

页面需要表达以下品牌性格：
- 精确
- 专业
- 工程感
- 可信
- 略带复古未来感
- 高信息密度但不杂乱
- 动效克制，不使用为了炫技而存在的效果

不要设计成常见的渐变色 SaaS 模板。
不要大量使用玻璃拟态、发光球体、3D 地球、悬浮卡片和无意义渐变。
不要用巨大圆角把所有元素都做成胶囊。
不要让每一个区块都争抢注意力。

二、七项设计原则

设计时必须明确体现：

1. 视觉层级：
   首屏标题是最高层级，正文、标签、辅助说明依次降低字号和对比度。

2. 对比：
   深色负责文本与结构，紫色负责交互和运行状态，黄色只用于主要 CTA，绿色只用于成功状态。

3. 对齐：
   全站使用统一内容容器和六列网格，标题、面板、图表和正文共享对齐基线。

4. 亲密性：
   相互关联的标题、状态、说明和操作必须被组织在同一个视觉分组中。

5. 重复与节奏：
   重复使用 FIG 编号、规则线、状态标签、等宽字体、统一间距和面板结构。

6. 平衡与留白：
   面板内部保持紧凑，页面区块之间使用充分留白，使高密度信息仍然容易阅读。

7. 统一与反馈：
   hover、active、loading、success、error、disabled 状态使用统一的颜色和动效规则。

四、组件语言

把每个核心功能设计成“仪器面板”。

每个面板包含：
- FIG 编号
- 模块名称
- 状态标签
- 标题与简短说明
- 终端输出、任务状态、数据表或 SVG 图表
- 必要操作按钮

统一使用：
- 1px 低透明度边框
- 小型等宽标签
- 点阵或细网格背景
- 方形或小圆角按钮
- 工程文档式分隔线
- 真实、有含义的数据内容

不要使用传统的大幅商业插画。
优先通过终端、代码、图表、状态、任务队列和指标表达产品能力。

五、页面结构

请至少设计：

1. 顶部导航
2. Hero 首屏
3. 核心能力概览
4. 3～6 个仪器面板式功能区块
5. 工作流程或数据流区块
6. 终端/运行状态展示
7. 最终 CTA
8. 页脚

页面阅读顺序应当是：
品牌主张 → 产品能力 → 工作方式 → 可信证据 → 行动按钮。

六、动效

动效只使用：
- opacity
- translate
- scale
- SVG stroke/path
- 少量 Canvas 背景

规则：
- 普通过渡 140～240ms
- 区块进入 400～600ms
- 使用统一 easing：cubic-bezier(0.22, 1, 0.36, 1)
- hover 位移不超过 2～4px
- 不进行滚动劫持
- 不使用持续晃动或大幅缩放
- 支持 prefers-reduced-motion

七、响应式和无障碍

- 桌面六列，平板两列，手机单列
- 移动端标题不小于 40px
- 触控目标至少 44×44px
- 正文具备足够行高
- 文本与背景满足 WCAG AA 对比度
- 所有交互支持键盘
- 提供清晰的 focus-visible 状态
- 颜色不能成为状态的唯一表达方式
