
>[!HINT] 易混淆
>符号名在**值上下文** → 取 JS 运行时实体 符号名在**类型上下文** → 取 TS 编译期类型

| 语法               | 产出 JS 运行时值 | 产出 TS 类型 |
| ---------------- | ---------- | -------- |
| `class A {}`     | ✅构造函数      | ✅实例类型 A  |
| `enum E {}`      | ✅枚举对象      | ✅枚举类型 E  |
| `namespace N{}`  | ✅JS 对象     | ✅类型容器 N  |
| `const enum E{}` | ❌无 JS      | ✅仅类型     |
| `type T = ...`   | ❌无 JS      | ✅仅类型     |
| `interface I{}`  | ❌无 JS      | ✅仅类型     |
