```js
class App {
  name = "";

  run() {
    console.log("run");
  }

  static version = 1;
}
```

这里的 `App` 表示实例类型，大概是：

```ts
{
  name: string;
  run(): void;
}

```

### 形式
1. App运行后 作为实例类型
```ts
1. <T> 形参
<TBase extends App>

2. 赋值
let app: App;
const app = new App();
```
2. AppConstructor运行后 作为构造函数类型
```ts
type AppConstructor<T> = new (...args: any[]) => T;
TBase extends AppConstructor<App>
```
