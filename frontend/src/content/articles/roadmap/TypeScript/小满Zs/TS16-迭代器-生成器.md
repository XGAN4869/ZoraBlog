# TS16：迭代器与生成器

## 一、先理解两个协议

### 1. Iterator 迭代器协议

迭代器对象必须提供 next 方法。每次调用都返回一个结果对象：

~~~ts
interface IteratorResult<T> {
  value: T | undefined
  done: boolean
}

interface Iterator<T> {
  next(): IteratorResult<T>
}
~~~

- done 为 false：本次还有一个有效 value；
- done 为 true：遍历结束，value 通常是 undefined。

### 2. Iterable 可迭代协议

可迭代对象必须提供 Symbol.iterator 方法，并返回一个迭代器。数组、字符串、Set、Map、NodeList、arguments 等都实现了这个协议。

普通对象默认没有 Symbol.iterator，因此不能直接使用 for...of。

## 二、生成器（Generator）

生成器函数使用 function* 声明，调用它不会立即执行函数体，而是返回一个同时满足 Iterable 和 Iterator 协议的生成器对象。它自带 next 方法。

~~~ts
function* gen() {
  // yield 可以产出 Promise，但普通生成器不会自动 await
  yield Promise.resolve('Zora')
  yield 'Raechel'
  yield 'Ruby'
  yield 'Kiran'
}

const female = gen()

console.log(female.next()) // { value: Promise<'Zora'>, done: false }
console.log(female.next()) // { value: 'Raechel', done: false }
console.log(female.next()) // { value: 'Ruby', done: false }
console.log(female.next()) // { value: 'Kiran', done: false }
console.log(female.next()) // { value: undefined, done: true }
~~~

> 生成器的执行顺序是同步且按 yield 顺序推进的。yield 出 Promise 不等于自动等待 Promise；如果需要异步等待，应使用 async function* 和 for await...of。

## 三、Set 与 Map

### 1. Set：保存不重复的值

~~~ts
const set: Set<number> = new Set([1, 2, 3, 1, 2, 3])
console.log(set) // Set(3) { 1, 2, 3 }
~~~

Set 适合去重，成员本身就是 value，没有单独的 key。

### 2. Map：保存 key-value 映射

Map 的 key 可以是任意类型，包括对象和数组。对象作为 key 时比较的是引用是否相同：

~~~ts
const map = new Map<readonly number[], string>()
const arr = [1, 2, 3] as const

map.set(arr, 'Zora')
console.log(map.get(arr)) // Zora
console.log(map.has(arr)) // true
~~~

如果使用内容相同但引用不同的数组，取不到同一项：

~~~ts
console.log(map.get([1, 2, 3])) // undefined
~~~

## 四、手动调用迭代器

~~~ts
function each(value: Iterable<unknown>): void {
  const iterator = value[Symbol.iterator]()
  let next = iterator.next()

  while (!next.done) {
    console.log(next.value)
    next = iterator.next()
  }
}

each(map)
~~~

对 Map 遍历时，value 是一个二元数组 [key, value]；对 Set 遍历时，value 就是集合成员本身。

## 五、for...of 是迭代器的语法糖

for...of 的大致执行过程是：先读取 value[Symbol.iterator]()，再循环调用 next()，直到 done 为 true。

~~~ts
for (const value of set) {
  console.log(value)
}
~~~

解构、数组展开等操作也会使用可迭代协议：

~~~ts
const a = [4, 5, 6]
const copy = [...a] // 数组展开会调用 a[Symbol.iterator]()
const [first, ...rest] = a // 数组解构同样依赖迭代器
~~~

## 六、让普通对象支持 for...of

给对象实现 Symbol.iterator，并返回一个带 next 方法的迭代器对象：

~~~ts
const range = {
  max: 5,
  [Symbol.iterator]() {
    let current = 0

    return {
      next(): IteratorResult<number> {
        if (current >= range.max) {
          return { value: undefined, done: true }
        }

        return {
          value: current++,
          done: false,
        }
      },
    }
  },
}

for (const value of range) {
  console.log(value) // 0、1、2、3、4
}
~~~

每次执行 range[Symbol.iterator]() 都会创建新的 current，因此同一个对象可以被多次独立遍历。

## 七、对象展开和数组展开的区别

~~~ts
const objectCopy = { ...range } // 对象展开：复制可枚举字符串键，不调用迭代器
const arrayCopy = [...range]    // 数组展开：调用 Symbol.iterator

console.log(objectCopy) // { max: 5 }
console.log(arrayCopy)  // [0, 1, 2, 3, 4]
~~~

这里要区分“展开”和“解构”：

- 对象展开或对象解构主要读取对象属性；
- 数组展开或数组解构需要对象可迭代。

## 八、同步生成器与异步生成器

普通生成器的 yield 不会自动等待 Promise：

~~~ts
function* syncGenerator() {
  yield Promise.resolve('同步生成器产出 Promise')
}
~~~

需要逐个等待异步结果时，可以使用异步生成器：

~~~ts
async function* asyncGenerator() {
  yield await Promise.resolve('Zora')
  yield 'Raechel'
}

for await (const name of asyncGenerator()) {
  console.log(name)
}
~~~

## 九、复习要点

1. Iterator 关注 next 方法，Iterable 关注 Symbol.iterator 方法。
2. Generator 对象既是迭代器，也是可迭代对象。
3. Set 用于去重，Map 用于 key-value 映射，Map 的对象 key 比较引用。
4. for...of、数组展开和数组解构都会使用 Symbol.iterator。
5. 普通对象默认不可迭代；实现 Symbol.iterator 后才能用于 for...of。
6. 处理异步 yield 时，区分普通生成器和异步生成器。
