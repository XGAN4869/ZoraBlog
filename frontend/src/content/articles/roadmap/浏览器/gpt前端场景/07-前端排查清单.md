# 把浏览器原理用到排查中

## 页面卡顿

1. 打开 Performance 面板录制。
2. 查看是否有 Long Task。
3. 检查主线程是否被循环、排序、JSON 处理或频繁 DOM 操作占用。
4. 必要时拆分任务或使用 Worker。

## 页面内存越来越大

1. 使用 Memory 面板拍摄多次 Heap Snapshot。
2. 比较仍然增长的对象。
3. 检查事件监听器、定时器、闭包和全局缓存。
4. 确认组件销毁时清理副作用。

## 首屏加载慢

1. 查看 Network 中脚本大小和加载时间。
2. 查看 Performance 中的解析、编译和脚本执行时间。
3. 使用代码分割、懒加载和减少首屏依赖。

## 递归报错

看到 `Maximum call stack size exceeded` 时，优先检查递归终止条件、组件递归和监听器互相触发。

## 记忆口诀

```text
卡顿看主线程
泄漏看堆快照
递归看调用栈
首屏看加载、解析和执行
重计算看 Worker
```
