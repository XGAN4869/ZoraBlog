- 进程是 每个正在运行的程序
	一个进程通常拥有自己独立的：
	内存空间（也就是虚拟地址）
	文件资源
	网络资源
	**环境变量**
	进程编号 PID

线程是 进程内部的一条执行路线
	线程共享所在进程的内存和资源
	多线程执行效率更高，所以线程有多条
- CPU 负责一条一条执行线程里的指令。
	并发：一个 CPU 核心快速切换多个任务，看起来像同时执行，操作系统就是这样干的
	并行：多个 CPU 核心真正同时执行多个任务
- 程序是“放在 硬盘 = 磁盘 上的文件

- JS 运行时【NodeJs为例】：从 JS 被加载开始，到 V8 管理它的解析、解释、编译、内存和运行环境的整个软件系统。**V8、Node.js、浏览器 JavaScript 引擎、事件循环、堆、垃圾回收等组成的运行环境**

c Rust 编译型语言编译出来的就是程序本身 ....exe 【提前把说明翻译好】
	C / Rust 源代码
	      ↓ 编译、链接
	可执行程序，例如 hello.exe（这一步直接启动）
	      ↓ 启动
	程序运行

Java Python js 解释型语言 通常把源代码交给相应的运行环境执行，不需要我先手动生成一个 `.exe`。
	Hello.java 源代码
	      ↓ javac 编译
	Hello.class 字节码
	      ↓ JVM 执行（JVM 内部在做解释/即时编译）
	程序运行
CMD、Bash、Zsh 是接收和执行命令的 Shell；PATH 是环境变量，帮助 Shell 找到要启动的程序。
