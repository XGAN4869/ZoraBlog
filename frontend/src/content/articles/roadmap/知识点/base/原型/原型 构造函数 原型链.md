
⚪构造函数：普通函数
	用 new  调用 → 它就扮演  构造函数 --- class function 声明的函数，开头大写都可以作为构造函数

⚪每一个构造函数的内部都有一个 prototype 属性，它的属性值是一个对象 --> Foo.prototype （记得大写不然分不清楚是 new 出来的 foo 还是 函数 Foo <font color="#4f81bd">作用：new Foo() 的时候，新实例的 [[Prototype]] 会被赋值为 Foo.prototype</font>

⚪`[[Prototype]]` 是 **ECMA 标准定义的内部槽**，不是可以直接用 `.` 访问的属性。拥有者：**一切 JS 对象**（实例、普通对象、甚至函数本身也有）

⚪new 出来实例后，你可以看下面的 new 的 steps，
	1. const newObj = Object.create({})                  // ① 创建全新空实例对象
	2. newObj.__proto__ = Foo.prototype       // ② 建立链接
	3. Foo.call(newObj,...agrs)                       // ③ 执行构造函数 把 Foo 的 this 绑定到 newObj 上
	4. return
	P.S. Constructor 即 构造函数
```js
function myNew(Constructor, ...args) {
  // 1. 创建新对象，将空对象的 [[Prototype]] 也就是 __proto__ = 构造函数的 .prototype
  const newObj = Object.create(Constructor.prototype);

  // 2. 调用构造函数，将 this 绑定到新对象
  const retVal = Constructor.call(newObj, ...args);  // ← 就是这一行

  // 3. 处理返回值
  return (typeof retVal === 'object' && retVal !== null) ? retVal : newObj;
  // 基于1，如果 return 回来的是 一个新的 newObj，这个 newObj 的 __proto__ 也就是 [[prototype]]是指向 Constructor.prototype 的
  //只要 构造函数不擅自写 return xxx 就没问题
}
```
使用场景：
```js
class A {}
class B {}
const a = myNew(A) === const a = new A()
const b = myNew(B,a) === const b = new B(new A())
```

#### 示例代码1
```js
//构造函数Foo
function Foo() {
    this.a = 1;
}
console.log(Foo.prototype);
//修改原型，如果没有正确维护constructor属性，导致其指向Object
Foo.prototype = {
    aa:10,
    bb:function(){
        console.log(20);
    },
    constructor:Foo
}
//创建实例foo
var foo = new Foo();
console.log(foo.aa);
//自身属性绑定了a:1
//通过原型继承的方式拿到原型属性
console.log('foo',foo);
// console.log('foo.prototype',foo.prototype); // 没有这个属性
console.log('true',foo.__proto__ === Foo.prototype);
console.log(Foo.prototype);
//[[Prototype]] 是一个内部属性，表示对象的原型链继承关系
// 这是每个 JavaScript 对象都有的隐藏属性，指向它的原型对象（即它的"父对象"）

console.log(Foo.prototype.constructor === Foo);
console.log(Foo.prototype.constructor);
```

#### 示例代码2
构造函数可以定义方法（通常写在原型上，但也可以写在构造函数内部赋值给 `this`）。无论哪种，当**实例**调用这些方法时，方法内部的 `this` 会指向**调用该方法的实例**，所以可以访问实例上的属性。

##### 方式一：方法定义在构造函数内部（直接给 this 赋值）

```js
function Foo(name) {
  this.name = name;
  this.sayName = function() {
    console.log(this.name);
  };
}
const f = new Foo('小红');
f.sayName();  // 小红 —— this 指向 f，所以能读取 f.name
```

##### 方式二：方法定义在原型上（更常见）

```js
function Foo(name) {
  this.name = name;
}
Foo.prototype.sayName = function() {
  console.log(this.name);
};
const f = new Foo('小刚');
f.sayName();  // 小刚 —— 调用时 this 指向 f，通过原型链找到了 sayName，但方法内部的 this 依然是 f
```

所以，无论是构造函数内部定义的方法，还是原型上的方法，**实例调用它们时，方法内的 `this` 都是实例本身**，因此可以访问实例的所有属性和原型链上的属性。
