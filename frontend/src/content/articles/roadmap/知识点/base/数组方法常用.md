## 具体知识点

### push / pop

`push` 从数组尾部添加一个或多个元素，返回新长度；`pop` 删除并返回最后一个元素。两者都会改变原数组。

```js
const list = ['a']
const length = list.push('b', 'c') // 3，list 变为 ['a', 'b', 'c']
const last = list.pop()            // 'c'，list 变为 ['a', 'b']
```

### shift / unshift

`unshift` 从数组头部添加元素并返回新长度；`shift` 删除并返回第一个元素。两者都会改变原数组。

```js
const queue = ['b', 'c']
queue.unshift('a') // ['a', 'b', 'c']
const first = queue.shift() // 'a'
```

### splice

从指定下标开始删除、插入或替换元素，返回“被删除元素组成的数组”，会改变原数组。

```js
const list = ['a', 'b', 'd']
list.splice(2, 0, 'c') // 插入，list -> ['a', 'b', 'c', 'd']
list.splice(1, 2, 'x') // 删除2项并插入，list -> ['a', 'x', 'd']
arr.splice(n,2)	       // 从 n 开始删 2 个
```

### fill / copyWithin

- `fill(value, start, end)` 用同一个值填充区间 `[start, end)`，会改变原数组。
- `copyWithin(target, start, end)` 把数组内部一段复制到另一位置，会改变原数组。

```js
new Array(3).fill(0) // [0, 0, 0]
const list = [1, 2, 3, 4]
list.copyWithin(1, 2) // [1, 3, 4, 4]
```

### forEach

遍历数组并执行副作用，没有返回值（返回 `undefined`），不能用 `break` 中断。

```js
list.forEach((item, index) => {
  console.log(index, item)
})
```

### map

遍历数组并将每一项转换成新值，返回长度相同的新数组，不改变原数组。

```js
const numbers = [1, 2, 3]
const doubled = numbers.map(item => item * 2) // [2, 4, 6]

// 补充字段：箭头函数使用括号包住对象字面量
const rows = numbers.map(item => ({ value: item, label: `第${item}项` }))
```

### filter

保留回调返回 `true` 的元素，返回新数组，不改变原数组。

```js
const enabled = rows.filter(item => item.value > 1)
```

### reduce / reduceRight

将数组累计成一个值，常用于求和、分组、去重、构造对象。`reduceRight` 从右向左执行。

```js
const total = [1, 2, 3].reduce((sum, item) => sum + item, 0) // 6
const byId = rows.reduce((result, item) => {
  result[item.value] = item
  return result
}, {})
```

### flat / flatMap

- `flat(depth)` 展开嵌套数组，默认展开一层；不会改变原数组。
- `flatMap(callback)` 等于先 `map` 再 `flat(1)`，适合“映射后展开一层”。

```js
const nested = [[1, 2], [3, [4]]]
nested.flat()    // [1, 2, 3, [4]]
nested.flat(2)   // [1, 2, 3, 4]

// 扁平化取出 child；没有 child 时保留当前 item
const totalTabs = computed(() => accountStore.menu.flatMap(item => {
  return Array.isArray(item.child) ? item.child : item
}))
```

### at / entries / keys / values

- `at(index)` 按下标取值，支持负数下标（`-1` 表示最后一项）。
- `entries()` 返回 `[index, value]` 的迭代器。
- `keys()` 返回下标迭代器；`values()` 返回值迭代器。

```js
const list = ['a', 'b', 'c']
list.at(-1) // 'c'
for (const [index, value] of list.entries()) {
  console.log(index, value)
}
```

### find / findLast

返回第一个（或最后一个）满足条件的元素；找不到返回 `undefined`。

```js
const first = rows.find(item => item.value > 1)
const last = rows.findLast(item => item.value > 1) // ES2023+
```

### findIndex / findLastIndex

返回第一个（或最后一个）满足条件元素的下标；找不到返回 `-1`。

```js
const index = rows.findIndex(item => item.value === 2)
const lastIndex = rows.findLastIndex(item => item.value === 2) // ES2023+
```

### some / every

- `some`：只要有一项满足条件就返回 `true`，常用于权限或存在性判断。
- `every`：所有项都满足条件才返回 `true`，常用于表单校验。

```js
const hasDisabled = rows.some(item => item.disabled)
const allValid = rows.every(item => item.value > 0)
```

### includes / indexOf / lastIndexOf

- `includes(value)` 判断是否包含值，返回布尔值，能正确判断 `NaN`。
- `indexOf(value)` 返回第一次出现的下标，找不到返回 `-1`。
- `lastIndexOf(value)` 返回最后一次出现的下标，找不到返回 `-1`。

```js
const list = [1, 2, 2, NaN]
list.includes(NaN)     // true
list.indexOf(2)        // 1
list.lastIndexOf(2)    // 2
```

### slice

截取 `[start, end)` 区间并返回新数组，不改变原数组；常用于浅拷贝：`arr.slice()`。

```js
const list = ['a', 'b', 'c', 'd']
list.slice(1, 3) // ['b', 'c']
```

### concat

合并数组或其他值并返回新数组，不改变原数组。

```js
[1, 2].concat([3], 4) // [1, 2, 3, 4]
```

### join

用指定分隔符把数组元素拼接成字符串，默认分隔符是逗号。

```js
['Vue', 'React', 'Svelte'].join(' / ') // 'Vue / React / Svelte'
```

### toString / toLocaleString

`toString` 将数组转换成逗号分隔的字符串；`toLocaleString` 会按当前语言环境格式化元素，金额、日期等场景更常用。

```js
[1, 2, 3].toString() // '1,2,3'
[1000, 2000].toLocaleString('zh-CN') // '1,000,2,000'
```

### sort / toSorted

`sort` 原地排序并改变原数组；`toSorted` 返回排序后的新数组（ES2023+）。数字排序必须提供比较函数。

```js
const numbers = [10, 2, 1]
numbers.sort((a, b) => a - b) // [1, 2, 10]
const sorted = numbers.toSorted((a, b) => b - a) // 不改变 numbers
```

### reverse / toReversed

`reverse` 原地反转并改变原数组；`toReversed` 返回反转后的新数组（ES2023+）。

```js
const list = [1, 2, 3]
const reversed = list.toReversed() // [3, 2, 1]，list 仍为 [1, 2, 3]
```

### toSpliced

`toSpliced` 是 `splice` 的不可变版本，返回修改后的新数组，不改变原数组（ES2023+）。

```js
const list = ['a', 'b', 'd']
const next = list.toSpliced(2, 0, 'c') // ['a', 'b', 'c', 'd']
```

### with

返回替换指定下标后的新数组，不改变原数组（ES2023+）。

```js
const list = ['待办', '进行中']
const next = list.with(0, '已完成')
```

### Array.isArray

准确判断一个值是不是数组。`typeof []` 的结果是 `"object"`，所以不要用 `typeof` 判断数组。

```js
Array.isArray([]) // true
Array.isArray({}) // false
```

### Array.from

把可迭代对象或类数组对象转换成真正的数组，也可以同时做映射。

```js
Array.from('abc') // ['a', 'b', 'c']
Array.from({ length: 3 }, (_, index) => index + 1) // [1, 2, 3]
```

### Array.of

用传入的参数创建数组，避免 `new Array(3)` 产生“长度为 3 的空数组”的特殊行为。

```js
Array.of(3)       // [3]
new Array(3)      // [空 × 3]
```

### Object.keys / values / entries

分别获取对象的自身可枚举键、值、键值对数组，常与 `for...of` 或 `Object.fromEntries` 配合使用。

```js
const user = { name: '小明', age: 18 }
Object.keys(user)    // ['name', 'age']
Object.values(user)  // ['小明', 18]
Object.entries(user) // [['name', '小明'], ['age', 18]]
```

### Object.fromEntries

把键值对数组转换成对象，是 `Object.entries` 的反向操作。

```js
const user = Object.fromEntries([
  ['name', '小明'],
  ['age', 18],
])
```

### Object.assign

把一个或多个源对象的**自身可枚举属性**复制到目标对象并返回目标对象。浅拷贝，后面的属性会覆盖前面的属性。

```js
const formData = { name: '', age: 0 }
Object.assign(formData, { name: '小明' })
const copy = Object.assign({}, formData) // 浅拷贝
```

### Object.hasOwn

判断属性是否是对象自身的属性，不会查找原型链（ES2022+）。旧项目可使用 `Object.prototype.hasOwnProperty.call(obj, key)`。

```js
Object.hasOwn({ name: '小明' }, 'name') // true
```

### Object.create / defineProperties

- `Object.create(proto)` 用指定原型创建对象；传入 `null` 可以创建无原型对象。
- `Object.defineProperties(obj, descriptors)` 一次定义多个属性。

```js
const user = Object.create(null)
Object.defineProperties(user, {
  name: { value: '小明', enumerable: true },
  age: { value: 18, enumerable: true },
})
```

### Object.is

判断两个值是否严格相同。与 `===` 的主要区别是：`Object.is(NaN, NaN)` 为 `true`，而 `Object.is(+0, -0)` 为 `false`。

```js
Object.is(NaN, NaN) // true
Object.is(+0, -0)   // false
```

### Object.getPrototypeOf / setPrototypeOf

获取或修改对象的原型。业务代码通常不建议频繁使用 `setPrototypeOf`，因为可能影响性能。

```js
const parent = { canRead: true }
const child = {}
Object.setPrototypeOf(child, parent)
Object.getPrototypeOf(child) === parent // true
```

### Object.getOwnPropertyNames / getOwnPropertySymbols

获取对象自身的属性名（包括不可枚举属性）或 `Symbol` 属性。`Object.keys` 只返回可枚举的字符串属性。

```js
Object.getOwnPropertyNames({ name: '小明' })
Object.getOwnPropertySymbols({ [Symbol('id')]: 1 })
```

### Object.defineProperty

精确设置属性的值、可枚举性、可写性和可配置性，默认情况下新属性不可枚举、不可写、不可配置。

```js
const user = {}
Object.defineProperty(user, 'id', {
  value: 1,
  enumerable: true,
  writable: false,
})
```

### Object.getOwnPropertyDescriptor(s)

- `getOwnPropertyDescriptor(obj, key)` 获取单个自身属性的描述符。
- `getOwnPropertyDescriptors(obj)` 获取全部自身属性描述符，适合保留 getter/setter 的拷贝。

```js
Object.getOwnPropertyDescriptor(user, 'id')
Object.getOwnPropertyDescriptors(user)
```

### Object.freeze / seal / preventExtensions

- `Object.freeze`：不能添加、删除、修改已有属性（浅冻结）。
- `Object.seal`：不能添加或删除属性，但可以修改已有属性。
- `Object.preventExtensions`：不能新增属性，已有属性仍可修改或删除。

```js
const config = Object.freeze({ api: '/users' })
```

### Object.isExtensible / isFrozen / isSealed

分别判断对象是否可扩展、是否被冻结、是否被密封。

```js
const config = Object.freeze({ api: '/users' })
Object.isExtensible(config) // false
Object.isFrozen(config)     // true
Object.isSealed(config)     // true
```
