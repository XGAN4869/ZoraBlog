### 区别：
- 继承式 extends：**is-a** 继承所有父类方法+属性，but 只能有一个父类。
> 	缺点
> 	1. 运行时无法继承了父类的子类行为
> 	2. 父子绑定，父改子也要改
- 

- 组合式 implements #编译后没了 : has-a 
	- ①拥有 interface 定义的接口的 字段、和方法签名 
	- ② implements class 的时候，和 interface 一样，**内部代码不会被实现，只检查类型** 
	- 使用场景：has-a 组合“当前类拥有一个能力对象”当前类通过成员对象调用或转发
> 	 注意
> 	implements 的字段还是要重新写一遍

- abstract class：① abstract 方法(只写签名无实现，子类要重写) ② 普通实体方法（有完整实现，子类可以直接继承复用）

P.S. 抽象类会编译成真实 JS 类，JS 产物是存在的；interface 编译后直接消失。

### Mixin的出现
使用场景：mixin“把这组能力混入当前类”方法直接出现在当前类上
Mixin：TS 靠**函数包装类**模拟多继承效果，以实现以下伪代码

```js
// TypeScript/JavaScript 不支持
class RectangleNode
  extends HTMLElement, Draggable, Selectable {}
```
why 不用多个 extends?  -- 用不了，一对一
why 不用 implements？ --无法继承代码，只给字段和方法签名
