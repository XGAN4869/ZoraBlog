#Defination
1. 如果一个函数访问了此函数的父级及父级以上的作用域变量，那么这个函数就是一个闭包。
2. 闭包会创建一个包含外部函数作用域变量的环境，并将其保存在内存中
#advantage
- 私有化变量
- 记住变量不被GC
- 延长作用域链
#易混淆 
- js 的 class 内部的 this.xxx 和 作用域链无关，JS的作用域链是纵向的，必须有嵌套关系，同级不行。而 Java 有类体作用域，也就是有横向的作用域链（可以暂时这样理解），所以调用同一个 class 下的方法不需要 this.xxx

## 示例2：变量私有
执行完 IIFE 后，它的作用域本应销毁，但因为返回的 `say` 函数仍然引用着 `val`，所以 `val` 所在的词法环境被保留下来，形成了**闭包**。
```js
let say = (function(){
  let val = 'hello world';   // 私有变量
  function say(){
    console.log(val);        // 内部函数访问私有变量
  }
  return say;                // 把内部函数暴露出去
})();
```

防抖是“回城被打断，重新读条”；  、节流是“技能进入 CD，冷却好了才能再放”
func 内部的 this === that === 返回函数的 this
⭐闭包能够保留 timer，能读到上一次的 timer 并清除，不然 timer 失效

>[!HINT]
> `debounce` 底下的 `timer` 是为了私有化/模块化变量，把这个变量的作用域链保留下来
> setTimeOut 本身是立即执行的
> 第一版可以用 value(方便理解), 第二版 ...args(传递更多的参数), 第三版 this(给类用的)

- 比如这里防抖函数要是不写 this, 就访问不到 name
```js
class UserManager {
  constructor(name) {
    this.name = name;
  }
  
  // 把防抖后的方法作为实例方法
  save = debounce(function() {
    console.log(`保存用户：${this.name}`); // 必须拿到 this.name
  }, 1000);
}

const manager = new UserManager('张三');
manager.save(); // 如果不转交 this，这里的 this 会是 undefined（严格模式）或 window
```
