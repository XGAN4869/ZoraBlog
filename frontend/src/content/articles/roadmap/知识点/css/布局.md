## 具体知识点

### 经典高度占满剩余空间
```vue
<template>
  <!-- 最外层容器 flex纵向，占满可视窗口高度 -->
  <div class="page-wrap">
    <div class="chat-bar">
      <!-- t-row 筛选栏 -->
    </div>
    <!-- 这里占剩余全部高度 -->
    <div class="chat-body"></div>
  </div>
</template>

<style lang="less" scoped>
.page-wrap {
  height: 100vh;
  display: flex;
  flex-direction: column;
}
.chat-bar {
  /* 高度自动，不需要写死 */
}
.chat-body {
  flex: 1;
  overflow: auto; /* 内容多了内部滚动，不会把页面撑出去 */
}
</style>
```


### position: relative / absolute
position 我一般按参照物来记。
static 是默认文档流；
relative 是相对自己原位置偏移；
absolute 是相对最近的非 static 祖先元素定位；
fixed 是相对视口定位，滚动时不动；
sticky 则是到了指定阈值后产生吸顶效果。

P.S. 一个元素上同时有 relative 和 absolute，后面的属性覆盖前面的属性

### 气泡对话
效果
- 气泡最多占容器 80% 宽度
- 蓝色背景、白字、圆角、四周留白
- ✅支持换行展示
- ✅超长文本自动折行，不会溢出
![[Pasted image 20260810160943.png]]

```vue
<div class="max-w-[80%] rounded-lg bg-blue-500 px-4 py-3 text-white whitespace-pre-wrap break-words"> 用户发送的消息内容 </div>
```
1. max-w-[80%]
	max-width:80%;
	短文字：气泡跟着文字宽度走；长文字：最多占 80% 宽度，然后自动换行，不会撑满整行。
2. whitespace-pre-wrap(重要！！！)
	white‑space: pre‑wrap;
	保留**换行符 `\n`**，接口返回的换行、用户输入的回车可以正常换行展示
3. break‑words
	word‑break: break‑words;
	遇到超长英文、长链接、长单词，强制截断换行，**不会把气泡撑破、不会出现横向滚动条**

### input框内元素不换行
```vue
<template #valueDisplay="{ value }">  
  <div class="flex flex-row items-center overflow-hidden">  
    <span class="mr-2 shrink-0">{{ value }}</span>  
    <t-tag  
        v-if="selectedOption?.modelType"  
        size="small"  
    >  
      {{ selectedOption.modelType }}  
    </t-tag>  
  </div>  
</template>
```
- `shrink‑0` → `flex‑shrink: 0` **禁止这个元素被压缩变小**
- `shrink` → `flex‑shrink: 1` **允许被压缩（默认值）**
- 重点是 items-center 和 overflow hidden 以及 flex-shrink
