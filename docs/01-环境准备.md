# 01 · 环境准备

这一节不写业务代码，只干一件事：**让你的电脑能跑 Go，并且能从国内下到依赖。**

## 1. 先搞懂三个词

Go 生态里有几个词网上到处出现但从没人解释，先花两分钟讲清楚，后面就不会晕。

### 「模块」和 `go.mod`

Go 从 1.11 开始用「模块（module）」管理项目。你执行 `go mod init 模块名` 的时候，
Go 会在当前目录生成一个 `go.mod` 文件，内容是：

```
module ganblog

go 1.25
```

这个东西的作用相当于前端的 `package.json`：**声明这个项目叫什么、用什么版本的 Go、依赖了哪些库**。
`go.mod` 旁边还有一个 `go.sum`，记录每个依赖的校验和（防止别人往你依赖的包塞恶意代码），
**这两个文件都要提交到 git**。

### 「依赖」和「驱动」

- **依赖**：你用到的第三方库。前端叫 `npm install`，Go 叫 `go get`，只是名字不同。
- **驱动（driver）**：一种特殊的依赖，负责让你的程序能和某个外部东西通信。
  最常见的场景就是**数据库驱动**——Go 自己不认识 MySQL 的通信协议，
  得装一个「MySQL 驱动」才连得上。

网上的教程说「装驱动」，翻译成人话就是：`go get 某个驱动包`。

### 「GOPROXY」

Go 默认从 `proxy.golang.org` 下载依赖。**这个地址在国内基本连不上**，
所以必须换成国内镜像，否则你会卡在下载依赖这一步，然后误以为是代码写错了。

> 你的机器上 Docker Hub 也是被墙的、已经配了镜像源——这是同一类问题，解法也一样：换镜像。

## 2. 安装 Go

### Windows（你的系统）

打开 PowerShell，执行：

```powershell
winget install GoLang.Go
```

装完**关掉 PowerShell 再重新打开**（让环境变量生效），然后验证：

```powershell
go version
```

应该输出类似 `go version go1.25.x windows/amd64` 的内容。

> 如果 `winget` 提示找不到，去 <https://go.dev/dl/> 下载 Windows 的 `.msi` 安装包，
> 双击一路下一步即可。**要求 go1.25 或更高**——因为最新的 Gin v1.12 最低要求 Go 1.25。

### 验证安装位置

```powershell
go env GOROOT    # Go 自己装在哪
go env GOPATH    # 你下载的依赖存在哪
```

`GOPATH` 默认是 `C:\Users\Glh\go`。依赖会下载到 `GOPATH\pkg\mod` 里，**是所有项目共享的一份缓存**，
不是每个项目一份——这点和 `node_modules` 不一样，所以不用每个项目重新下一遍。

## 3. 配置国内代理（关键一步）

**只做一次，全局生效。**

```powershell
go env -w GOPROXY=https://goproxy.cn,direct
```

含义：

- `https://goproxy.cn` —— 七牛云维护的国内 Go 模块镜像，速度快
- `,direct` —— 兜底：如果镜像上没有这个包，就直接去源站抓

备选的国内镜像（第一个不好用再换）：

- `https://mirrors.aliyun.com/goproxy/`（阿里云）

验证配置生效：

```powershell
go env GOPROXY
# 应该输出 https://goproxy.cn,direct
```

### 如果下载依赖时卡在「verifying module」

Go 下载依赖后还要去校验和数据库核对。如果卡在这一步，先试试多等一会儿；
实在不行再执行下面这条改用国内校验镜像，然后重新运行刚才的 `go get`：

```powershell
go env -w GOSUMDB=off
```

> ⚠️ `GOSUMDB=off` 会关掉依赖的防篡改校验，属于**降低安全性换速度**的手段。
> 只在真的卡住时用。恢复默认：`go env -u GOSUMDB`。

## 4. 常用命令速查

这一节后面会反复用到，可以回来查。

| 命令 | 干什么 | 前端里的对应物 |
|------|--------|--------------|
| `go mod init 名字` | 初始化一个新项目，生成 `go.mod` | `npm init` |
| `go get 包路径@latest` | 安装/升级一个依赖 | `npm install 包名` |
| `go mod tidy` | 清理没用到的依赖，补齐缺的 | `npm prune` + 补装 |
| `go run .` | 编译并运行当前目录的程序 | `npm run dev`（但不带热重载） |
| `go build .` | 只编译，产出一个可执行文件 | `npm run build` |
| `go vet ./...` | 静态检查，抓常见错误 | `eslint` |
| `go fmt ./...` | 格式化代码（Go 强制统一风格） | `prettier` |

> `go run` **不会**自动重启。改完代码要手动 `Ctrl+C` 再跑一次。
> 想要热重载得另外装 `air` 这类工具，前期没必要，先手动重启。

## 5. 在仓库里初始化后端

现在 `backend/` 目录里只有 `Dockerfile` 和 `.dockerignore`，还没有 Go 代码。

```powershell
cd C:\Project\每日练习\aiAssistCoding\Go_React_Blog\backend

go mod init ganblog
```

**为什么叫 `ganblog` 而不是 `github.com/你/ganblog`？**
`go mod init` 的参数是「模块路径」，通常写成仓库地址（比如 `github.com/ganlh/ganblog`）。
但那是给**别人 import 你的代码**用的。你这是本地私有项目，不会有人 import，
所以起个短名字最省事。以后内部包会这样引用：`ganblog/internal/model`。

执行完，`backend/` 下会多出 `go.mod`。确认一下：

```powershell
type go.mod
```

```
module ganblog

go 1.25
```

> 到此为止**还没有写任何 Go 代码**，但环境已经准备好了。下一节写第一行代码。

## 6. 装依赖

依赖不是一次全装完，而是**用到哪个装哪个**，跟着后面的章节走。这里先给总表：

```powershell
cd C:\Project\每日练习\aiAssistCoding\Go_React_Blog\backend

# 第 2 节：Web 框架
go get github.com/gin-gonic/gin@latest

# 第 3 节：登录 token + 密码加密
go get github.com/golang-jwt/jwt/v5@latest
go get golang.org/x/crypto@latest

# 第 4 节：数据库
go get gorm.io/gorm@latest
go get gorm.io/driver/mysql@latest

# 收尾：清掉没用的、补上缺的
go mod tidy
```

每天 `go get` 完，`go.mod` 里会多一行 `require`，`go.sum` 里会多几行校验和。**都是正常的**。

注意 `golang.org/x/crypto` 这个包：它是一个大礼包，里面有很多加密相关的子包，
你要的只是其中的 `golang.org/x/crypto/bcrypt`（密码哈希）。下载时是整个包一起下，不用管。

## 7. 常见报错对照表

遇到报错先来这里查，多数是环境问题不是代码问题。

| 报错 | 原因 | 怎么办 |
|------|------|--------|
| `go: command not found` | Go 没装好，或环境变量没生效 | 关掉终端重开；还不行就重装 Go |
| `dial tcp ... i/o timeout` 下载依赖时 | 没配国内代理 | 回到第 3 节配 `GOPROXY` |
| `missing go.sum entry` | 依赖没下全 | `go mod tidy` |
| `package xxx is not in std` | 依赖没装 | `go get xxx@latest` |
| `go.mod file not found` | 不在 `backend/` 目录里执行 | `cd` 到有 `go.mod` 的那一层 |
| `undefined: gin` | 忘了 import | 看后面章节里代码顶部的 `import (...)` |
| `concurrent map writes` 崩溃 | 多请求同时读写 map | 第 3 节会讲怎么加锁 |
